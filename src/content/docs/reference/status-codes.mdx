The working set. Reasoning and trade-offs are in [Status codes](/http/status-codes/); error bodies are in [Errors](/http/errors/). Every 4xx and 5xx response carries an `application/problem+json` body.

## 2xx: success

| Code                  | Use it when                                          | Goes with                            |
| --------------------- | ---------------------------------------------------- | ------------------------------------ |
| <Status code={200} /> | The request succeeded and the response has a body.   |                                      |
| <Status code={201} /> | A resource was created.                              | `Location`, the created resource     |
| <Status code={202} /> | Work was accepted and will finish later.             | `Location` of the operation resource |
| <Status code={204} /> | The request succeeded and there's nothing to return. | No body                              |
| <Status code={206} /> | A `Range` request was served in part.                | `Content-Range`                      |
| <Status code={207} /> | A batch has per-item outcomes.                       | A body with a status per item        |

## 3xx: redirection

| Code                  | Use it when                                                           | Goes with                                            |
| --------------------- | --------------------------------------------------------------------- | ---------------------------------------------------- |
| <Status code={303} /> | A download or result lives elsewhere, for example at a presigned URL. | `Location`                                           |
| <Status code={304} /> | The client's cached copy is still current.                            | `ETag`, no body                                      |
| <Status code={308} /> | A resource moved permanently and the method must be kept.             | `Location`. Many API clients don't follow redirects. |

## 4xx: the client can fix it

| Code                  | Use it when                                                                                                         | Goes with                       |
| --------------------- | ------------------------------------------------------------------------------------------------------------------- | ------------------------------- |
| <Status code={400} /> | The request can't be parsed: malformed JSON or a broken header.                                                     |                                 |
| <Status code={401} /> | Credentials are missing, expired or invalid.                                                                        | `WWW-Authenticate`              |
| <Status code={403} /> | The caller is known but not allowed to do this.                                                                     |                                 |
| <Status code={404} /> | The resource doesn't exist, or the caller mustn't learn that it does.                                               |                                 |
| <Status code={405} /> | The resource doesn't support this method.                                                                           | `Allow`                         |
| <Status code={406} /> | No representation matches `Accept`.                                                                                 |                                 |
| <Status code={409} /> | The request conflicts with the resource's current state, such as cancelling a shipped order.                        | A specific problem type         |
| <Status code={410} /> | The resource was removed on purpose, after a sunset.                                                                | Link to the replacement         |
| <Status code={412} /> | An `If-Match` or `If-Unmodified-Since` precondition failed.                                                         | Current `ETag`                  |
| <Status code={413} /> | The body exceeds the documented limit.                                                                              |                                 |
| <Status code={415} /> | The request's `Content-Type` isn't supported.                                                                       | `Accept-Post` or `Accept-Patch` |
| <Status code={422} /> | The request parses, but values fail validation: a wrong type, an unknown field or parameter, an out-of-range value. | Per-field `errors`              |
| <Status code={428} /> | The operation requires a precondition header, such as `If-Match`.                                                   |                                 |
| <Status code={429} /> | The client exceeded its rate limit or quota.                                                                        | `Retry-After`, `RateLimit`      |

## 5xx: the server or something behind it failed

| Code                  | Use it when                                                  | Goes with              |
| --------------------- | ------------------------------------------------------------ | ---------------------- |
| <Status code={500} /> | An unexpected failure. Log the details; return none of them. | A trace or instance ID |
| <Status code={501} /> | The server doesn't support the method at all.                |                        |
| <Status code={502} /> | An upstream service returned an invalid response.            |                        |
| <Status code={503} /> | The service is temporarily overloaded or in maintenance.     | `Retry-After`          |
| <Status code={504} /> | An upstream service didn't answer in time.                   |                        |

## Codes to avoid in APIs

| Code                                         | Why                                                                                                                    |
| -------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------- |
| <Status code={301} />, <Status code={302} /> | Clients may change `POST` to `GET` on redirect. Use <Status code={308} /> or <Status code={307} />, or don't redirect. |
| <Status code={200} /> with an error body     | Every generic client, proxy and dashboard counts it as success.                                                        |
| <Status code={418} />                        | RFC 2324, published on 1 April 1998. A joke worth knowing, not a code worth sending.                                   |
