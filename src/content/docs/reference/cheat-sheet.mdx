Print it, pin it, paste it into your PR template. Each section links back to the lesson that explains the _why_.

## Resources & URLs

- [ ] URLs name **things**; methods name actions. No verbs in paths. [→](/course/resources-and-urls/thinking-in-resources/)
- [ ] Actions modelled as field updates, new resources, or calculated results.
- [ ] Domain words, not generic ones (`/shipments`, not `/items`).
- [ ] Collections **plural**, paths **kebab-case**, query params **snake_case**. [→](/course/resources-and-urls/url-style-guide/)
- [ ] No trailing slashes, no `/api` prefix, URL-safe IDs.
- [ ] Nest only things that live inside a parent; max ~3 levels. [→](/course/resources-and-urls/relationships-and-nesting/)
- [ ] Every nested lookup is **scoped by parent and caller**.

## HTTP

- [ ] `GET` never changes state. [→](/course/speaking-http/http-methods/)
- [ ] `PUT` replaces, `PATCH` merges (JSON Merge Patch), `POST` creates.
- [ ] `201` + `Location` for creations; `204` for empty successes. [→](/course/speaking-http/status-codes/)
- [ ] Most specific status code; never errors in a `200`.
- [ ] Errors as **Problem Details** (`application/problem+json`). [→](/course/speaking-http/errors/)
- [ ] No stack traces; a trace ID instead.
- [ ] Standard headers before custom ones; a correlation ID propagated. [→](/course/speaking-http/headers/)

## Payloads

- [ ] One property case everywhere (e.g. `snake_case`). [→](/course/payloads/json-style/)
- [ ] Top-level responses are **objects**.
- [ ] Enums as `UPPER_SNAKE_CASE` strings, documented as extensible.
- [ ] `null` ≡ absent; no `null` booleans; `[]` not `null`. [→](/course/payloads/null-absent-empty/)
- [ ] RFC 3339 timestamps (`*_at`), ISO country/language/currency codes. [→](/course/payloads/data-formats/)
- [ ] Money = decimal amount **+ currency**. IDs are strings.

## Collections

- [ ] Paginated from day one, with a max page size. [→](/course/collections/pagination/)
- [ ] Cursor pagination, opaque cursors, `next` links.
- [ ] Conventional params: `q`, `sort`, `fields`, `embed`, `limit`, `cursor`. [→](/course/collections/querying/)
- [ ] Compression on; `ETag` + `If-None-Match`; caching is explicit. [→](/course/collections/performance-and-caching/)

## Robustness

- [ ] Non-idempotent `POST`s accept an `Idempotency-Key` (or a natural unique key). [→](/course/robustness/idempotency/)
- [ ] Concurrent updates protected with `ETag` + `If-Match` → `412`. [→](/course/robustness/optimistic-locking/)
- [ ] Slow work → `202` + job resource; batches → `207`. [→](/course/robustness/async-and-batch/)
- [ ] `429` + `Retry-After` for rate limits. [→](/course/robustness/rate-limiting/)

## Evolution

- [ ] Only additive, backward-compatible changes. [→](/course/evolution/compatibility/)
- [ ] Clients are tolerant readers (unknown fields & enum values).
- [ ] A versioning strategy chosen, and rarely needed. [→](/course/evolution/versioning/)
- [ ] Deprecations: spec flag, `Deprecation`/`Sunset` headers, usage monitoring. [→](/course/evolution/deprecation/)

## Production

- [ ] Every endpoint authenticated; least-privilege scopes. [→](/course/production/security/)
- [ ] **Object-level** authorization on every access.
- [ ] Absolute links in the body (`self`, `next`, related). [→](/course/production/hypermedia/)
- [ ] Spec has title, SemVer version, owner, audience; published to a catalog. [→](/course/production/docs-and-operations/)

## Events

- [ ] Event types registered, owned, schema-versioned. [→](/course/events/events-as-apis/)
- [ ] Metadata: `eid`, `event_type`, `occurred_at`.
- [ ] Per-entity ordering (partition key / version).
- [ ] Consumers deduplicate and ignore stale events; no personal data in events. [→](/course/events/consuming-events/)
